## Архитектура управления службами в Windows

В отличие от систем на базе `systemd` в Linux, управление фоновыми процессами и службами (daemons) в операционной системе Windows реализовано через службу диспетчера управления службами (**Service Control Manager — SCM**).

PowerShell предоставляет объектный интерфейс для взаимодействия с SCM. Для выполнения большинства операций, связанных с изменением состояния служб (запуск, остановка, изменение параметров конфигурации и типа запуска), требуется запуск консоли PowerShell **от имени администратора**.

---
## Таблица основных командлетов управления службами

|**Командлет PowerShell**|**Описание**|
|---|---|
|`Get-Service`|Получает список служб или подробную информацию о конкретной службе.|
|`Start-Service`|Запускает остановленную службу.|
|`Stop-Service`|Принудительно останавливает работающую службу.|
|`Restart-Service`|Выполняет перезапуск службы (последовательная остановка и повторный запуск).|
|`Set-Service`|Изменяет параметры службы (тип запуска: автоматический, ручной, отключен).|
|`New-Service`|Создает новую службу в системе (требует указания исполняемого файла).|

## Получение информации и аудит служб

### Вывод списка всех служб

```PowerShell
Get-Service
```

### Получение информации о конкретной службе

Для точечного запроса используется параметр `-Name` или точное имя службы (например, служба обновлений Windows `wuauserv`):

```PowerShell
Get-Service -Name wuauserv
```

### Фильтрация работающих служб

С помощью конвейера и командлета `Where-Object` (или его псевдонима `where`) отбираются исключительно активные службы:

```PowerShell
Get-Service | Where-Object {$_.Status -eq "Running"}
```

## Управление состоянием служб

_Внимание: Для выполнения команд изменения состояния требуется повышенный уровень привилегий (административная сессия PowerShell)._

### Остановка службы

Остановка службы печати `spooler`:

```PowerShell
Stop-Service -Name spooler
```

### Запуск службы

Запуск ранее остановленной службы:

```PowerShell
Start-Service -Name spooler
```

### Перезапуск службы

Выполнение цикла остановки и запуска службы одной командой:

```PowerShell
Restart-Service -Name spooler
```

## Изменение параметров запуска и конфигурации

Командлет `Set-Service` позволяет изменять конфигурационные параметры службы, включая режим ее инициализации при старте системы.

### Установка автоматического запуска

```PowerShell
Set-Service -Name wuauserv -StartupType Automatic
```

### Отключение службы

```PowerShell
Set-Service -Name wuauserv -StartupType Disabled
```

_Допустимые значения для параметра `-StartupType`:_

- `Automatic` — автоматический запуск при старте системы;
- `Manual` — запуск вручную;
- `Disabled` — служба полностью отключена.

## Справочник командлетов управления службами

|**Задача**|**Командлет / Пример**|**Описание**|
|---|---|---|
|**Список всех служб**|`Get-Service`|Вывод состояния всех сервисов|
|**Поиск службы**|`Get-Service -Name spooler`|Получение информации по имени|
|**Запуск службы**|`Start-Service -Name name`|Перевод службы в статус Running|
|**Остановка службы**|`Stop-Service -Name name`|Завершение работы службы|
|**Перезапуск**|`Restart-Service -Name name`|Перезагрузка сервиса|
|**Тип запуска**|`Set-Service -Name name -StartupType Manual`|Изменение параметров автозагрузки|

## Заключение

Инструментарий PowerShell для работы со службами Windows обеспечивает полный контроль над жизненным циклом фоновых процессов. Использование стандартизированных командлетов семейства `Service` позволяет легко интегрировать управление сервисами в скрипты автоматизации, развертывания программного обеспечения и регламентного обслуживания систем.
