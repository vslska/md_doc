## Архитектура NetworkManager и утилиты `nmcli`

`nmcli` — это инструмент командной строки для управления службой `NetworkManager` и отчета о состоянии сети. Он позволяет создавать скрипты автоматизации и выполнять любые сетевые настройки без использования графического интерфейса.

```text
               [ Пользователь / Скрипт ]
                          │
                          ▼
                   [ nmcli (CLI) ]
                          │
                          ▼  D-Bus API
             [ NetworkManager (Системная служба) ]
                          │
         ┌────────────────┴────────────────┐
         ▼                                 ▼
[ Ядро Linux / wpa_supplicant ]    [ Файлы конфигурации ]
         │                                 │
         ▼                                 ▼
 Сетевое железо (Wi-Fi / Ethernet)    (/etc/NetworkManager/system-connections/)
````

## Базовый синтаксис и управление состояниями

### Управление состоянием сетевой службы

- Проверка общего статуса NetworkManager:
 
```Bash
nmcli general status
```

- Включение или отключение сетевых интерфейсов (Network on/off):

```bash
nmcli networking off
nmcli networking on
```

### Управление физическими интерфейсами (device)

- Проверка доступных сетевых устройств и их статуса:

```Bash
nmcli device status
```

- Сканирование доступных Wi-Fi сетей:

```Bash
nmcli device wifi list
```

- Подключение к открытой или защищенной Wi-Fi сети (интерактивно или с параметрами):

```Bash
nmcli device wifi connect "SSID_NAME" password "secret_password"
```

- Отключение устройства от сети:

```Bash
nmcli device disconnect wlan0
```

## Управление профилями подключений (connection)

NetworkManager разделяет физические устройства (`device`) и профили настроек (`connection`). Один интерфейс может иметь несколько сохраненных профилей подключений.

- Просмотр всех сохраненных профилей в системе:

```Bash
nmcli connection show
```

- Запуск (активация) существующего профиля:

```Bash
nmcli connection up "con-name"
```

- Остановка (деактивация) профиля:

```Bash
nmcli connection down "con-name"
```

- Удаление профиля подключения:
 
```Bash
nmcli connection delete "con-name"
```

## Создание и настройка стандартных подключений

### Создание проводного подключения (Ethernet)

Пример создания профиля для проводной сети с фиксированным (статическим) IP-адресом:

```Bash
nmcli connection add type ethernet con-name "office-lan" ifname eth0 \
  ip4 192.168.1.100/24 gw4 192.168.1.1 \
  ipv4.dns "8.8.8.8,8.8.4.4"
```

### Создание стандартного домашнего Wi-Fi подключения (WPA2/WPA3 Personal)

```Bash
nmcli connection add type wifi con-name "home-wifi" ifname wlan0 ssid "MyHomeNetwork" \
  wifi-sec.key-mgmt wpa-psk \
  wifi-sec.psk "my_secure_password"
```

---
## Расширенная настройка: Корпоративный Wi-Fi (WPA-EAP / PEAP)

Для подключения к защищенным корпоративным сетям (например, университетским или офисным точкам доступа с протоколами аутентификации 802.1X) используется конфигурация с протоколом PEAP и внутренним методом MSCHAPv2.

```Bash
nmcli connection add type wifi con-name "corporate-secure" ifname wlan0 ssid "Corp-WiFi" \
  wifi-sec.key-mgmt wpa-eap \
  802-1x.eap peap \
  802-1x.identity "domain\\username" \
  802-1x.password "user_password" \
  802-1x.phase2-auth mschapv2
```

### Дополнительные параметры безопасности для EAP

Если корпоративная сеть требует проверки сертификата удостоверяющего центра (CA), профиль можно дополнить параметром пути к сертификату:

```sh
nmcli connection modify "corporate-secure" \
802-1x.ca-cert "/etc/ssl/certs/ca-corporate.pem"
````

## Модификация существующих подключений

Утилита позволяет изменять параметры уже созданных профилей без их пересоздания с помощью команды `modify` (`mod`).

- Изменение типа аутентификации или параметров IPv4:

```Bash
nmcli connection modify "home-wifi" ipv4.method manual ipv4.addresses 192.168.0.50/24
```

- Перезагрузка профиля для применения изменений:

```
nmcli connection up "home-wifi"
```

## Справочник команд `nmcli`

|**Задача**|**Команда**|**Описание**|
|---|---|---|
|**Статус сети**|`nmcli general status`|Проверка общего состояния службы|
|**Список устройств**|`nmcli device status`|Отображение сетевых карт и их статусов|
|**Сканирование Wi-Fi**|`nmcli device wifi list`|Поиск доступных беспроводных сетей|
|**Список профилей**|`nmcli connection show`|Вывод всех сохраненных конфигураций|
|**Активация профиля**|`nmcli connection up <name>`|Подключение к сети по сохраненному профилю|
|**Создание EAP-PEAP**|`nmcli connection add ...`|Настройка корпоративного Wi-Fi[cite: 9]|
|**Удаление профиля**|`nmcli connection delete <name>`|Полное удаление конфигурации|

## Заключение

Инструмент `nmcli` предоставляет полный спектр возможностей для управления сетевым стеком Linux на уровне ядра и службы NetworkManager. Знание базовых команд и параметров создания профилей (включая сложные корпоративные стандарты вроде WPA-EAP/PEAP) позволяет эффективно автоматизировать администрирование сетевых интерфейсов в скриптах конфигурации и на инфраструктурных серверах.
