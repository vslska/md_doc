# Vim

> **Назначение:** систематическое руководство по текстовому редактору Vim: от базовой навигации до продвинутого редактирования, работы с регистрами, макросами, окнами, вкладками, Ex-командами, конфигурацией и автоматизацией.  
> **Основной ориентир:** Vim 9.x. Базовый функционал совместим с Vim 8.x.  
> **Примечание:** Vim и Neovim имеют общее ядро команд и концепций, однако механизмы конфигурации, API и экосистемы расширений существенно различаются.

## Что такое Vim

**Vim (Vi IMproved)** — модальный текстовый редактор, созданный на основе концепций классического редактора `vi`.

Ключевой принцип управления:
Клавиши ввода определяют **операции над текстом**, а не исключительно непосредственный ввод символов. Изучение Vim строится на понятии грамматики команд:

```text
operator + motion
```

Примеры композиции:

```text
dw  ## d (delete) — удалить; w (word) — до начала следующего слова
```

```text
ci" ## c (change) — изменить; i" (inner quotes) — содержимое внутри двойных кавычек
```

## Установка и проверка

Проверка установленной версии и параметров сборки:

```bash
vim --version ## Вывод версии Vim, включенных компонентов и путей конфигурации
```

Запуск редактора с чистым профилем:

```bash
vim --clean ## Запуск Vim без загрузки пользователских файлов .vimrc и плагинов
```

Определение директории ресурсов (runtime) внутри редактора:

```vim
:echo $VIMRUNTIME " Вывод пути к каталогу с системными скриптами и документацией
```

Просмотр полной информации о сборке:

```vim
:version " Отображение списка всех включенных и отключенных компилятором функций
```

## Ментальная модель Vim

Структура команд в Normal mode подчиняется строгому иерархическому шаблону:

```text
MODE
  ↓
OPERATOR
  ↓
MOTION / TEXT OBJECT
  ↓
COUNT
```

Примеры применения:

```text
3dw  ## 3 — счетчик (3 раза); d — удалить; w — слово (удаление трех слов)
d$   ## d — удалить; $ — от текущего положения курсора до конца строки
ci(  ## c — изменить; i( — содержимое внутри круглых скобок
yap  ## y — скопировать; ap — весь абзац с внешним пробельным интервалом
2dd  ## 2 — счетчик (2 раза); dd — текущая строка (удаление двух строк)
```

## Режимы Vim

| Режим | Назначение |
|---|---|
| Normal | Навигация, выполнение операторов и управление структурой файла |
| Insert | Непосредственный ввод и редакция текста |
| Visual | Посимвольное, построчное или блочное выделение текста |
| Command-line | Ввод Ex-команд (`:`), поисковых запросов (`/`, `?`) и команд shell |
| Replace | Замещение существующего текста вводимым с сохранением длины строк |

Возврат в Normal mode из любого другого режима:

```text
Esc ## Переход в Normal mode
```

Переход в Insert mode:

```text
i ## Вход в режим ввода перед курсором
a ## Вход в режим ввода после курсора
o ## Вставка новой строки снизу и переход в режим ввода
O ## Вставка новой строки сверху и переход в режим ввода
I ## Вход в режим ввода в начале строки (на первом непробельном символе)
A ## Вход в режим ввода в конце строки
```

Переход в Visual mode:

```text
v      ## Вход в посимвольный Visual mode (characterwise)
V      ## Вход в построчный Visual mode (linewise)
Ctrl-v ## Вход в блочный Visual mode (blockwise)
```

Переход в Command-line mode:

```vim
: " Вызов командной строки Ex
```

## Запуск и открытие файлов

Открытие отдельного файла:

```bash
vim file.txt ## Открытие одного файла
```

Передача нескольких файлов в аргументах:

```bash
vim file1.txt file2.txt ## Открытие списка файлов (argument list)
```

Открытие файла в режиме «только для чтения»:

```bash
vim -R file.txt ## Открытие файла в режиме Read-Only
```

Запуск в изолированном окружении:

```bash
vim --clean file.txt ## Открытие файла без пользовательских конфигураций
```

## Выход и сохранение

Сохранение изменений:

```vim
:w " Запись изменений в текущий файл
```

Завершение работы:

```vim
:q " Закрытие текущего окна (если нет несохраненных изменений)
```

Сохранение и выход:

```vim
:wq " Запись изменений и завершение работы
:x  " Запись изменений (только при их наличии) и завершение работы
```

Принудительный выход без сохранения изменений:

```vim
:q! " Завершение работы с отбрасыванием несохраненных изменений
```

Принудительная запись (например, в файлы с ограничением прав доступа при наличии sudo-прав):

```vim
:w! " Принудительное сохранение текущего буфера
```

Сохранение под новым именем:

```vim
:w new-name.txt " Запись текущего буфера в указанный новый файл
```

## Навигация

### Посимвольное перемещение

```text
h ## Перемещение курсора влево
j ## Перемещение курсора вниз
k ## Перемещение курсора вверх
l ## Перемещение курсора вправо
```

### В пределах строки

```text
0 ## Переход на первый символ строки (колонка 0)
^ ## Переход на первый непробельный символ строки
$ ## Переход на последний символ строки
```

### По словам и структурам

```text
w ## Перемещение к началу следующего слова (разделитель — знаки пунктуации и пробелы)
W ## Перемещение к началу следующего WORD (разделитель — только пробелы)
b ## Перемещение к началу предыдущего слова
B ## Перемещение к началу предыдущего WORD
e ## Перемещение к концу текущего или следующего слова
E ## Перемещение к концу текущего или следующего WORD
```

### По видимой области экрана

```text
H ## Переход на верхнюю строку экрана (High)
M ## Переход на среднюю строку экрана (Middle)
L ## Переход на нижнюю строку экрана (Low)
```

### По файлу

```text
gg     ## Переход на первую строку файла
G      ## Переход на последнюю строку файла
42G    ## Переход на строку 42
:42    ## Переход на строку 42 через Ex-команду
Ctrl-f ## Прокрутка на одну страницу вперед (down)
Ctrl-b ## Прокрутка на одну страницу назад (up)
Ctrl-d ## Прокрутка на пол-экрана вниз
Ctrl-u ## Прокрутка на пол-экрана вверх
```

## Основные операции редактирования

### Замена символов:

```text
r ## Замена символа под курсором без перехода в Insert mode
s ## Удаление символа под курсором с переходом в Insert mode
```

### Основные операторы базового редактирования:

```text
c ## Изменение (удаление с переходом в Insert mode)
d ## Удаление
y ## Копирование (yank)
p ## Вставка скопированного текста после курсора
P ## Вставка скопированного текста перед курсором
```

## Операторы и motions

Базовые операторы:

```text
d  ## Удаление текста
c  ## Изменение текста
y  ## Копирование в регистр
>  ## Увеличение отступа (indent)
<  ## Уменьшение отступа (unindent)
=  ## Автоматическое выравнивание отступов
g~ ## Инверсия регистра символов
gu ## Приведение символов к нижнему регистру
gU ## Приведение символов к верхнему регистру
```

Применение оператора к текущей строке выполняется путем дублирования символа оператора:

```text
dd ## Удаление текущей строки
cc ## Очистка текущей строки с переходом в Insert mode
yy ## Копирование текущей строки
```

Комбинации операторов с числовыми коэффициентами:

```text
3dd ## Удаление трех строк, начиная с текущей
2yy ## Копирование двух строк
5cc ## Изменение пяти строк
```

```text
X   ## Удаление символа перед курсором

3dd ## Удаление трех строк

P   ## Вставка текста из unnamed register перед/выше курсора
d$  ## Удаление текста от курсора до конца строки
dw  ## Удаление текста от курсора до начала следующего слова
di" ## Удаление содержимого внутри двойных кавычек
```

```text
v      ## Включение посимвольного выделения

```

## Отмена и повтор


```text
ciwText<Esc> ## Изменение слова под курсором на "Text"

.            ## Автоматическое повторение изменения слова на "Text"
```

## Поиск

```text
/pattern ## Поиск шаблона pattern в направлении от курсора к концу файла
?pattern ## Поиск шаблона pattern в направлении от курсора к началу файла
n        ## Переход к следующему совпадению в направлении поиска
N        ## Переход к предыдущему совпадению в направлении поиска
*        ## Поиск точного совпадения слова под курсором в направлении вперед
##        ## Поиск точного совпадения слова под курсором в направлении назад
```

Управление чувствительностью к регистру через Ex-команды:

```vim
:set ignorecase " Игнорирование регистра при поиске
:set smartcase  " Учет регистра только при наличии заглавных букв в поисковом запросе
:nohlsearch     " Снятие подсветки текущих совпадений поиска
```

## Замена

Общий синтаксис Ex-команды подстановки:

```vim
:[range]s/{pattern}/{replacement}/[flags]
```

Примеры применения:

```vim
:s/foo/bar/     " Замена первого совпадения 'foo' на 'bar' в текущей строке
:s/foo/bar/g    " Замена всех совпадений 'foo' на 'bar' в текущей строке
:%s/foo/bar/g   " Замена всех совпадений 'foo' на 'bar' во всем файле
:%s/foo/bar/gc  " Замена всех совпадений во всем файле с запросом подтверждения
:%s/foo/bar/gi  " Замена без учета регистра букв во всем файле
:10,20s/foo/bar/g " Замена всех совпадений 'foo' на 'bar' со строки 10 по 20
```

Использование альтернативных разделителей для исключения экранирования спецсимволов:

```vim
:%s##old/path##new/path##g " Замена путей с использованием '##' в качестве разделителя
```

## Регистры

Просмотр текущего содержимого регистров:

```vim
:registers " Отображение содержимого всех активных регистров
```

Запись и вставка с использованием именованных регистров (`"a` - `"z`):

```text
"ayy ## Копирование текущей строки в регистр 'a'
"ap  ## Вставка содержимого из регистра 'a'
```

Черная дыра (Black Hole Register - `"_`), исключающая перезапись основных регистров:

```text
"_dd ## Удаление строки без сохранения ее содержимого в каком-либо регистре
```

Использование системного буфера обмена (требуется сборка Vim с поддержкой `+clipboard`):

```text
"+y ## Копирование текста в системный буфер обмена (CLIPBOARD)
"+p ## Вставка текста из системного буфера обмена (CLIPBOARD)
"*y ## Копирование текста в выделение X11 (PRIMARY)
"*p ## Вставка текста из выделения X11 (PRIMARY)
```


## Текстовые объекты

Текстовые объекты применяются в сочетании с операторами (`d`, `c`, `y`):

```text
iw ## inner word (содержимое слова без окружающих пробелов)
aw ## a word (слово с прилегающими пробелами)
i" ## inner quotes (содержимое внутри двойных кавычек)
a" ## a quotes (содержимое кавычек вместе с самими кавычками)
i' ## inner single quotes (содержимое внутри одинарных кавычек)
a' ## a single quotes (содержимое с одинарными кавычками)
i( ## inner parenthesis (содержимое внутри круглых скобок)
a( ## a parenthesis (содержимое вместе с круглыми скобками)
i[ ## inner bracket (содержимое внутри квадратных скобок)
a[ ## a bracket (содержимое вместе с квадратными скобками)
i{ ## inner brace (содержимое внутри фигурных скобок)
a{ ## a brace (содержимое вместе с фигурными скобками)
ip ## inner paragraph (содержимое абзаца)
ap ## a paragraph (абзац с прилегающими пустыми строками)
is ## inner sentence (содержимое предложения)
as ## a sentence (предложение с прилегающими пробелами)
it ## inner tag (содержимое внутри HTML/XML тега)
at ## a tag (HTML/XML тег целиком с открывающим и закрывающим элементами)
```

Примеры использование операций:

```text
ciw ## Изменение текущего слова
di" ## Удаление текста внутри кавычек
ya( ## Копирование выражения в скобках вместе со скобками
```

## Повторение команд и автоматизация

Повторное выполнение последней Ex-команды:

```text
:@: ## Повтор выполнения последней Ex-команды
```

## Mappings

Переопределение клавиш (mappings):

```vim
" Назначение комбинации <Leader>w для сохранения файла в Normal mode
nnoremap <leader>w :write<CR>

" Назначение пробела в качестве клавиши <Leader>
let mapleader = " "

" Быстрый выход из Insert mode по двойному нажатию 'j'
inoremap jj <Esc>

" Копирование выделения в системный буфер в Visual mode
vnoremap <leader>y "+y
```

Виды команд назначения биндингов:

```text
:noremap  — Рекурсивное переопределение для всех режимов (не рекомендуется)
:nnoremap — Нерекурсивное переопределение для Normal mode
:inoremap — Нерекурсивное переопределение для Insert mode
:vnoremap — Нерекурсивное переопределение для Visual mode
:xnoremap — Нерекурсивное переопределение для Visual mode (без Select mode)
:tnoremap — Нерекурсивное переопределение для Terminal mode
```

## Антипаттерны

1. **Изучение Vim исключительно как последовательности горячих клавиш.**  
   Необходимо применять концепцию композиции операторов и объектов: `operator + motion / text-object`.
2. **Перегрузка конфигурации плагинами.**  
   Использование десятков внешних плагинов без освоения стандартных Ex-команд приводит к падению производительности редактора.
3. **Игнорирование различий между буферами, окнами и вкладками.**  
   Вкладки в Vim представляют собой сохраненные конфигурации сетки окон (layouts), а не единичные файлы.
4. **Необоснованное применение команды `:q!`.**  
   Применение `:q!` без проверки причин блокировки ведет к потере несохраненных изменений.

```text
iw i" i( ip ## Внутри слова, внутри кавычек, внутри скобок, внутри абзаца
```

## Заключение

Vim представляет собой формальный **язык преобразования текста**.

Фундаментальная модель выполнения операций:

```text
COUNT + OPERATOR + MOTION / TEXT OBJECT
```

Использование данной модели обеспечивает последовательную автоматизацию операций редактирования с минимальным количеством нажатий клавиш.
