# Vim — практическая шпаргалка

> Практическая шпаргалка по Vim: от первых движений до macros, registers, text objects, окон и продвинутого редактирования.
> 
> Главная идея Vim:
> 
> ```text
> оператор + движение = действие над текстом
> ```
> 
> Например:
> 
> ```text
> d + w = удалить слово
> c + i + " = изменить содержимое кавычек
> y + $ = скопировать до конца строки
> ```
> 
> Если понять эту модель, Vim перестаёт быть набором случайных хоткеев.

# 1. Главная модель Vim

Vim работает не как обычный текстовый редактор.

Вместо:

```text
нажал кнопку → сделал действие
```

Vim использует:

```text
оператор + движение
```

Например:

```text
dw
```

означает:

```text
d = delete
w = word
```

То есть:

> удалить до следующего слова.

Другие примеры:

```text
cw
```

изменить слово.

```text
yw
```

скопировать слово.

```text
d$
```

удалить до конца строки.

```text
c$
```

изменить до конца строки.

```text
y$
```

скопировать до конца строки.

Это одна из самых важных концепций Vim.

Если ты только начинаешь, выучи эти:

# 4. Перемещение

Основные:

```text
h    ←
j    ↓
k    ↑
l    →
```

То есть:

```text
    k
    ↑
h ←   → l
    ↓
    j
```

---

## Почему не стрелки?

Потому что руки остаются около основной позиции:

```text
       k
       ↑
   h ←   → l
       ↓
       j
```

Со временем это становится значительно удобнее.

# 14. Повтор команды

Одна из самых мощных клавиш Vim:

```text
.
```

`.` повторяет последнее изменение.

Например:

```text
dw
```

Удалил слово.

Теперь:

```text
.
```

Удалит следующее слово.

Ещё:

```text
ciwhello<Esc>
```

После этого:

```text
.
```

повторит изменение.

# 17. Замена

Заменить первое совпадение в строке:

```text
:s/old/new/
```

Все совпадения в строке:

```text
:s/old/new/g
```

Во всём файле:

```text
:%s/old/new/g
```

С подтверждением:

```text
:%s/old/new/gc
```

Где:

```text
c = confirm
```

Очень полезная команда:

```text
:%s/foo/bar/gc
```

Vim будет спрашивать для каждого совпадения.

# 18. Text Objects

Это одна из причин, почему Vim становится невероятно мощным.

Основные:

```text
iw     inner word
aw     a word

i"     внутри "
a"     вместе с "

i'     внутри '
a'     вместе с '

i(     внутри ()
a(     вместе с ()

i[     внутри []
a[     вместе с []

i{     внутри {}
a{     вместе с {}
```

---

## Пример

Есть:

```text
hello("world")
```

Курсор внутри `world`.

Нажать:

```text
ci"
```

Получишь:

```text
hello("")
```

И сразу режим Insert.

Напиши:

```text
Vim
```

Получишь:

```text
hello("Vim")
```

# 24. Макросы

Одна из самых крутых фишек Vim.

Начать запись:

```text
qa
```

где `a` — register.

Выполняешь действия.

Остановить:

```text
q
```

Запустить:

```text
@a
```

Повторить последний macro:

```text
@@
```

---

## Пример

Есть:

```text
alice
bob
charlie
david
```

Нужно превратить в:

```text
user=alice
user=bob
user=charlie
user=david
```

Можно записать:

```text
qa
```

Дальше:

```text
Iuser=
Esc
j
q
```

Теперь:

```text
@a
```

И ещё:

```text
@@
```

# 36. Комментарии

Встроенного универсального comment toggle в классическом Vim нет.

Но можно использовать Visual Block.

Например:

```text
Ctrl+v
```

Потом:

```text
I
```

Написать:

```text
#
```

И:

```text
Esc
```

Vim вставит `#` во все выбранные строки.

```text

```


```text
:100
```

```text
:10,20d
```

Удалить строки 10–20.

```text
:10,20y
```

---

Переместить:

```text
:10,20m30
```

Переместить строки 10–20 после строки 30.

# 44. Минимальный `.vimrc`

```vim
" Номера строк
set number

" Относительные номера
set relativenumber

" Подсветка синтаксиса
syntax on

" Автоматические отступы
set autoindent
set smartindent

" Размер tab
set tabstop=4
set shiftwidth=4
set expandtab

" Поиск без учёта регистра
set ignorecase

" Но если есть uppercase — учитывать регистр
set smartcase

" Подсветка найденного
set hlsearch

" Incremental search
set incsearch

" Не создавать swap-файлы в текущей директории
set directory^=$HOME/.vim/swap//

" Более приятный статус
set laststatus=2

" Показывать текущую позицию
set ruler

" Поддержка clipboard
set clipboard=unnamedplus
```

# 47. `f` и `t`

Очень полезные движения.

Найти символ вперед:

```text
fa
```

Курсор прыгнет на следующий `a`.

До символа:

```text
ta
```

Курсор остановится перед `a`.

Назад:

```text
Fa
Ta
```

---

## Повтор

После:

```text
fa
```

следующий такой символ:

```text
;
```

Назад:

```text
,
```

Это очень быстро для редактирования кода.

# 58. Мощная формула Vim

Большинство действий можно строить так:

```text
[count] + operator + motion
```

Например:

```text
3dw
```

означает:

```text
3 × delete × word
```

---

Другой вариант:

```text
d + i + "
```

Получаем:

```text
di"
```

То есть:

```text
delete
+
inside
+
quotes
```


# 70. Полезные regex в Vim

Начало строки:

```text
^
```

Конец:

```text
$
```

Любой символ:

```text
.
```

Любое количество:

```text
*
```

Например:

```text
:%s/^/# /
```

Добавить `#` в начало каждой строки.

---

Удалить пустые строки:

```text
:g/^$/d
```

---

Удалить строки содержащие `DEBUG`:

```text
:g/DEBUG/d
```

---

Оставить только строки содержащие `ERROR`:

```text
:v/ERROR/d
```

Очень мощные команды.

---

# 71. Команда `:g`

Формула:

```text
:g/pattern/command
```

Например:

```text
:g/TODO/d
```

Удалить все строки с `TODO`.

---

```text
:g/ERROR/p
```

Показать строки с ERROR.

---

```text
:g/^$/d
```

Удалить пустые строки.

---

# 72. `:v`

Обратное условие.

```text
:v/ERROR/d
```

Удалит всё, что НЕ содержит `ERROR`.

# 92. Главное правило

Не пытайся запомнить Vim как:

```text
"dd = удалить строку"
"ciw = изменить слово"
"gg = начало файла"
```

Лучше запомнить Vim как систему:

```text
ОПЕРАТОР
    +
ДВИЖЕНИЕ
    =
ДЕЙСТВИЕ
```

Например:

```text
d + w   → удалить слово
c + w   → изменить слово
y + w   → скопировать слово
```

А затем:

```text
d + i + "
c + i + "
y + i + "
```

И:

```text
d + i + (
c + i + (
y + i + (
```

Когда эта модель становится привычной, огромное количество команд Vim начинает **выводиться логически**, а не заучиваться.

> **Vim не нужно помнить целиком. Нужно научиться комбинировать его части.**
