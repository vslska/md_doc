
## Основы sed
Команда `sed` преобразует текст из файлов или из стандартного ввода, используя последовательность инструкций, которую называют `sed`-сценарием.

Вызову сценарий
```bash
$ sed script input-files
```
или использую параметр `-e` для поддержки нескольких сценариев, которые последовательно обрабатывают ввод:
```bash
$ sed -e script1 -e script2 -e script3 input-files
```
Также можно хранить `sed`-сценарии в файлах и обращаться к ним с параметром `-f`, тогда они будут запускаться последовательно:
```bash
$ sed -f script-file1 -f script-file2 -f script-file3 input-files
```
Наиболее часто используемым сценарием является подстановка, которая заменяет одни строки другими. 
```bash
s/regexp/replacement/
```
> **regexp** — регулярное выражение для сопоставления с каждой входной строкой.
> **replacement** — строка для замены совпадающего текста.

> [!важн.]
> При вводе `sed`-сценария в командной строке заключай его в кавычки, чтобы оболочка не вычисляла специальные символы `sed. При необходимости используй одинарные или двойные кавычки.


Косая черта  `/` в подстановке может быть *заменена* любым другим удобным
символом. Это полезно, когда само регулярное выражение включает слеш,
который в противном случае пришлось бы экранировать. Следующие три
сценария sed эквивалентны:

```bash
s/one/two/
s_one_two_
s@one@two@
```

Параметр `i` делает совпадения нечувствительными к регистру:
```bash
$ echo Efficient Stuff | sed "s/stuff/linux/" # чувствит. к регистру
$ echo Efficient Stuff | sed "s/stuff/linux/i" # не чувств к регистру
```

`g` (global) заменяет все вхождения регулярного выражения, а не только первое:
```bash
$ echo efficient stuff | sed "s/f/F/" # Заменяет первую букву
$ echo efficient stuff | sed "s/f/F/g"
```

 `sed`-сценарий  **удаление**, удаляющий строки по их номеру:
```bash
seq 1 5 | sed 3d # удаляет  3 строку 
1
2
4
5 
```

Сценарий, **удаляющий** строки, которые соответствуют *регулярному выражению*:
```bash
$  seq 1 10 | sed '/[13579]$/d' # Удаляет строки заканч. на нечетные
2
4
6
8
10
```


## Сопоставление подвыражений в `sed` (Backreferences)

**Подвыражения** (или «обратные ссылки») позволяют `sed` не просто находить текст, но и запоминать его части, чтобы затем менять их местами, удалять или дублировать.

### 1. Основы синтаксиса

Чтобы **создать** подвыражение, часть регулярного выражения заключается в экранированные круглые скобки: `\( ... \)`.
- Первая пара скобок создает группу `\1`.
- Вторая — `\2`, и так далее (до `\9`).
---
### 2. Простой пример: перенос цифры

**Задача:** Изменить `image.jpg.1` на `image1.jpg`.

1. **Шаблон поиска:** `image\.jpg\.\([1-3]\)`
> - `image\.jpg\.` — ищет точное совпадение текста (точка экранируется, чтобы не значить «любой символ»).
 > - `\([1-3]\)` — находит цифру от 1 до 3 и **сохраняет** её в ячейку памяти №1.
2. **Шаблон замены:** `image\1.jpg`
> -  `\1` — вставляет то, что было найдено в первых скобках.

**Команда**:
```bash
$ ls | sed "s/image\.jpg\.\([1-3]\)/image\1.jpg/"
```
---
### 3. Сложный пример: изменение структуры имени

**Задача:** Изменить `apple.jpg.1` на `apple1.jpg`.

Здесь нам нужно разбить строку на три переменные части:

1. **Имя (слово):** `\([a-z][a-z]*\)` — сохраняется в `\1`.
2. **Расширение (3 буквы):** `\([a-z][a-z][a-z]\)` — сохраняется в `\2`.
3. **Номер (цифра):** `\([0-9]\)` — сохраняется в `\3`.
---
### Сборка команды

Между группами мы ставим экранированные точки `\.`, которые разделяют их в исходном имени файла.

**Полная конструкция:**

- **Найти:** `\([a-z][a-z]*\)\.\([a-z][a-z][a-z]\)\.\([0-9]\)`
- **Заменить на:** `\1\3.\2` (Имя + Цифра + Точка + Расширение)

**Команда:**

```bash
$ ls | sed "s/\([a-z][a-z]*\)\.\([a-z][a-z][a-z]\)\.\([0-9]\)/\1\3.\2/"
```

**Результат:**

- `apple.jpg.1` → `apple1.jpg`
- `banana.png.2` → `banana2.png`
---
### 4. Как это применить для реального переименования?

`sed` сам по себе только печатает текст в консоль. Чтобы переименовать файлы, результат работы `sed` обычно передают в оболочку (shell).

Один из способов — использование цикла или утилиты `rename`, но классический метод через `sed` выглядит так (генерация команд `mv`):
```bash
ls *.jpg.* | sed -E 's/([a-z]+)\.([a-z]+)\.([0-9]+)/mv & \1\3.\2/' | sh
```

>_Здесь использован флаг `-E` (расширенные регулярные выражения), который позволяет писать скобки `()` без обратных слэшей для удобства._
