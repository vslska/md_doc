# Интерактивный Fish: Потоки, кавычки, списки, окружение и магия автодополнения

## Потоки ввода-вывода и синтаксис перенаправления

В Fish механизмы перенаправления (`>`, `>>`, `2>`) работают с дескрипторами `stdin (0)`, `stdout (1)` и `stderr (2)` логичнее и проще, чем в Bash. Самое главное — **в Fish нет оператора `2>&1`**, который постоянно ломает логику в Bash.

Справочник операторов перенаправления в Fish

|Синтаксис|Назначение и действие|Реальный пример в Fish|
|---|---|---|
|`> file`|Перенаправление `stdout` в файл (с перезаписью)|`echo "v2.0" > version.txt`|
|`>> file`|Перенаправление `stdout` в файл в режиме добавления|`echo "Success" >> log.txt`|
|`2> file`|Перенаправление строго ошибок `stderr` в файл|`tar -czf b.tar.gz /data 2> err.log`|
|`2>> file`|Перенаправление `stderr` в файл в режиме добавления|`systemctl restart nginx 2>> failures.log`|
|`&> file`|**Слияние потоков:** Направить и `stdout`, и `stderr` в файл|`ansible-playbook site.yml &> run.log`|
|`&>> file`|Дописать и `stdout`, и `stderr` в конец файла|`scripts/test.py &>> total.log`|
|`^ file`|_Устаревший синтаксис:_ Перенаправление `stderr` (в Fish 3.0+ используйте `2>`)|`command ^ err.log`|

Разбор физики слияния потоков в конвейере

В Bash для передачи ошибок в пайп приходится писать `command 2>&1 | grep`. В Fish для этого создан чистый и понятный синтаксис:
```shell
# Направить и стандартный вывод, и поток ошибок на вход утилиты grep
make build &| grep -i "error"
```

## Кавычки и экранирование

Как и в Bash, пробел в Fish разделяет аргументы. Но логика работы кавычек имеет свои важные особенности:

- **Одинарные кавычки (`'...'`)**: Полное, жесткое экранирование. Текст внутри воспринимается абсолютно буквально. Переменные не раскрываются. Единственный символ, который нужно экранировать внутри них — это сам апостроф (`\'`).
- **Двойные кавычки (`"..."`)**: Мягкое экранирование. **Разрешают** раскрытие переменных (`$VAR`).
- **⚠️ Главное отличие от Bash:** Внутри двойных кавычек в Fish **обратный слэш `\` теряет свою экранирующую силу** перед большинством символов. Он работает только для экранирования самого знака доллара (`\$`), кавычки (`\"`), слэша (`\\`) и спецсимволов (`\n`, `\t`).

```shell
# В Bash это выведет: test\path
# В Fish это выведет: test\path (слэш не исчезает перед обычной буквой!)
echo "test\path"
```

## Переменные в Fish: Концепция списков (Arrays)

В Fish **все переменные под капотом являются списками (массивами)**. Если переменная содержит один элемент — это просто список из одного элемента. Пробелов вокруг знака равенства здесь нет, потому что самого знака `=` для присвоения в Fish не существует.

### Базовое присвоение через `set`

Для работы с переменными используется встроенная команда `set`:

```shell
# Задание локальной переменной
set TARGET_ENV "production"

# В отличие от Bash, здесь можно безопасно ставить пробелы для читаемости:
set TARGET_ENV "production"
```


### Локальные, Глобальные и Универсальные переменные

Fish делит переменные по областям видимости с помощью флагов:

- `--local` (`-l`): Переменная видна только внутри текущего блока кода (например, внутри функции или цикла).
- `--global` (`-g`): Переменная видна во всей текущей сессии терминала.
- `--export` (`-x`): Экспортирует переменную в окружение (Environment) для дочерних процессов (аналог `export VAR=val` в Bash).
- `--universal` (`-u`): **Киллер-фича Fish.** Переменная сохраняется в конфигах Fish на диске. Она мгновенно становится доступна **во всех параллельно открытых терминалах** и переносит свое значение даже после полной перезагрузки сервера!
```shell
# Объявить переменную окружения для дочерних процессов (например, для Go или Python)
set -gx DATABASE_URL "postgres://localhost:5432/db"

# Сделать переменную универсальной (сохранить навсегда без правки конфигов)
set -ux EDITOR "vim"
```

### Ловушка: Как правильно работать со `$PATH` в Fish

Поскольку `$PATH` — это список, в Fish больше не нужно склеивать пути через двоеточие (`PATH=$PATH:/new/path`). Для управления путями есть встроенная утилита `fish_add_path`:

```shell
# Безопасно добавить кастомный путь в начало $PATH (переменная обновится перманентно)
fish_add_path /opt/bin
```

## Автоматизация и конфигурация: `config.fish`

У Fish нет файлов `.bashrc` или `.bash_profile`. Вся конфигурация, алиасы и функции прописываются в одном месте: `$HOME/.config/fish/config.fish`.

### Киллер-фича Fish: Сокращения (`abbr`) вместо Алиасов (`alias`)

В отличие от классического `alias` (который просто скрытно подменяет команду во время выполнения), механизм **`abbr` (Abbreviations)** работает как интерактивный текстовый автозаменятель на лету.

**Физика процесса:** Когда ты создаешь аббревиатуру (например, `gco` для `git checkout`) и нажимаешь **Пробел** или **Enter** в терминале, Fish **мгновенно разворачивает** `gco` в полный текст `git checkout` прямо на экране перед твоими глазами.

В чем профит перед `alias` в реальной работе:

1. **Чистая история:** В историю команд (`fish_history`) сохраняется не безликое сокращение `gco`, а **полная команда** со всеми флагами. Если через месяц ты будешь искать по `Ctrl+R` сложную команду, ты её легко найдешь.
2. **Защита от забывания синтаксиса:** Ты всегда видишь реальные флаги утилит, которые запускаешь, и не забываешь чистый системный синтаксис Linux.
3. **Безопасность при шаринге экрана:** Когда ты показываешь коллеге экран, люди видят стандартные команды, а не твои кастомные тайные сокращения.

#### Практическое применение `abbr` и `alias`:

```
# --- Вариант А: Классические алиасы (работают как быстрые функции под капотом) ---
alias k="kubectl"
alias ll="ls -lAh"

# --- Вариант Б: Мощные аббревиатуры (разворачиваются по пробелу) ---
# Быстрый переход к логам Nginx
abbr -a tailn "tail -f /var/log/nginx/access.log"

# Тяжелая конструкция для Docker (развернется мгновенно, сохранив читаемость истории)
abbr -a dps "docker ps --format 'table {{.Names}}\t{{.Status}}\t{{.Ports}}'"
```


#### Трюк: Как прописать аббревиатуру навсегда БЕЗ правки конфигов

Если добавишь флаг универсальности `-U`, аббревиатура запишется в глобальные перманентные настройки Fish на диске. Тебе даже не придется открывать `config.fish`:

```shell
# Записать универсальную аббревиатуру "навсегда" прямо из консоли
abbr -a -U k "kubectl"
```


#### Как временно отменить развертывание?

Если тебе нужно отправить команду, которая совпадает с твоей аббревиатурой, но ты не хочешь, чтобы Fish её разворачивал: напиши её и нажмите **`Control+Space` (Ctrl + Пробел)** вместо обычного пробела. Fish оставит короткий текст как есть.

## Подгрузка изменений на лету

В отличие от Bash, где нужно делать `source ~/.bashrc`, Fish автоматически отслеживает изменения в своих функциях. Но если ты жестко переписал `config.fish` руками и хочешь применить изменения прямо в текущей сессии:

```shell
source $HOME/.config/fish/config.fish
```

## Магия автодополнения и история команд

Интерактивная работа — это то, ради чего выбирают Fish. Ему не нужны плагины вроде `zsh-autosuggestions`, всё вшито в движок.

### Смарт-автодополнение (Autosuggestions)

Когда ты начинаешь вводить команду, Fish серым цветом подставляет наиболее вероятное продолжение, основываясь на твоей истории и установленных в системе `man`-страницах.

- **`Arrow Right` (Стрелка вправо) или `Ctrl+F`**: Принять предложение полностью.
- **`Alt+Arrow Right` (Alt + Стрелка вправо) или `Alt+F`**: Принять предложение частично (только следующее слово).

### Поиск по истории со стрелками

В Fish нет неудобных Bang-команд (типа `!!` или `!$`), они здесь заменены визуальным поиском.

1. Начни писать имя команды (например, `docker run`).
2. Нажимай **`Arrow Up` (Стрелка вверх)**.
3. Fish начнет фильтровать историю и показывать только те команды, которые _начинались_ с этого префикса.

### Ловушка: Как в Fish сделать аналог `sudo !!`?

Так как конструкции `!!` в Fish физически не существует, стандартный Bash-трюк «забыл поставить sudo» не сработает.

- **Решение:** Нажми **`Alt+S`**. Fish автоматически подставит слово `sudo` в самое начало текущей (или предыдущей) командной строки.

### Полнотекстовый поиск по истории (`Ctrl+R`)

Если нужно найти команду не по первому слову, а по контексту (например, ты помнишь только порт `8080`):

1. Нажми **`Ctrl+R`** (откроется встроенный интерактивный пейджер истории).
2. Начни вводить `8080`.
3. Листай список стрелками `Up/Down` и нажмите `Enter` для выбора.

## Горячие клавиши редактирования (Fish-стиль)

По умолчанию Fish использует раскладку, близкую к Emacs, но оптимизированную под современную клавиатуру.

- **`Alt+.`**: Вставляет последний аргумент предыдущей команды (точно так же, как в Bash).
- **`Ctrl+W`**: Вырезать одно слово слева от курсора.
- **`Alt+D`**: Удалить одно слово справа от курсора.
- **`Ctrl+K`**: Вырезать текст от курсора до конца строки.
- **`Ctrl+U`**: Вырезать всю текущую строку целиком.
- **`Ctrl+Y`**: Вставить (Yank) ранее вырезанный текст.
- **`Alt+W`**: Показать краткое описание (short man page) для утилиты под курсором.
- **`Alt+H`**: Открыть полную man-страницу для текущей команды.

## Веб-интерфейс настройки: `fish_config`

Уникальная фича Fish, которой нет ни в одном другом шелле — графический конфигуратор.  
Если тебе надоело ковырять цвета терминала и вид промпта (prompt) в текстовых файлах, запусти прямо в терминале:

```bash
fish_config
```

Fish поднимет локальный веб-сервер и автоматически откроет вкладку в твоем браузере. Там можно мышкой выбрать тему оформления, настроить цвета подсветки синтаксиса, внешний вид строки приглашения и посмотреть текущие алиасы. При закрытии вкладки веб-сервер сам остановится, а настройки сохранятся в `$HOME/.config/fish/`.
