# Системные утилиты ядра Linux: Генерация, фильтрация и трансформация потоков

----
## Генерация данных и последовательностей

### date (Управление временем)

Выводит или форматирует системное время. Форматирование начинается со знака `+`.

```bash
# ISO-формат даты (удобно для именования бэкапов): 2026-01-19
date +%Y-%m-%d

# Вывод текущего дня недели на языке локали
date +"Today is %A"
```
### seq vs Brace Expansion (Генерация диапазонов)

Для генерации чисел используются либо внешняя утилита `seq`, либо встроенный механизм шелла `{x..y}`.

- **`seq` (Внешняя утилита):** Работает с дробным и отрицательным шагом. Разделитель по умолчанию — `\n`.
 
```bash
# Сгенерировать числа от 8 до 12 с ведущими нулями для одинаковой ширины
seq -w 8 12  # Вывод: 08, 09, 10, 11, 12
    
 # Диапазон от 3 до 0 с обратным шагом -1
seq 3 -1 0
```

- **Brace Expansion (Встроенный макрос):** Выполняется силами шелла _до_ запуска команд. Не генерирует процессы.

```
# Инкремент шагом 100: от 1 до 1000
echo {1..1000..100}

 # Генерация буквенных диапазонов (seq так не умеет)
echo {A..Z}
```

### yes (Генерация ответов и стресс-тесты)

Бесконечно генерирует строку (по умолчанию `y`) в `stdout`. Идеально для автоматизации интерактивных консольных утилит (например, `fsck` или устаревших инсталляторов).

```bash
# Автоматически отвечать "yes" на все запросы интерактивной утилиты
yes | fsck /dev/sdb1

# Ограничение генерации с помощью SIGPIPE от head
yes "Data line" | head -n 3
```

## Рекурсивный поиск файлов (find)

Утилита `find` сканирует дерево директорий напрямую через системные вызовы VFS ядра, минуя алфавитную сортировку шелла, что делает её максимально быстрой.

#### Оптимальные фильтры

```
# Искать строго файлы (-type f), заканчивающиеся на .conf, игнорируя регистр букв (-iname)
find /etc -type f -iname "*.conf"
```

_⚠️ Важное правило продакшена:_ Шаблон имени (`*.conf`) **обязательно** нужно закрывать в кавычки. Иначе шелл раскроет маску (глоббинг) локально в текущей папке _до_ запуска `find`, и поиск сломается.

#### ⚠️ Оптимизация деструктивных действий (`-exec`)

Классический синтаксис `find ... -exec rm {} \;` — это скрытый убийца производительности на Highload. Знак `;` заставляет ядро порождать новый изолированный процесс `rm` под каждый найденный файл. Если файлов миллион — сервер уйдёт в жесткий `Load Average`.

**Эффективные альтернативы удаления:**

```bash
# Вариант А: Использование знака плюс (+). Объединяет пути в один системный вызов (быстро)
find /var/log/app -type f -name "*.tmp" -exec rm -f {} +

# Вариант Б (Наилучший): Встроенное удаление на уровне VFS ядра без порождения процессов
find /var/log/app -type f -name "*.tmp" -delete
```

## Фильтрация и потоковый анализ текста

### grep (Регулярные выражения)

Поиск строк по шаблону.

- `grep -w "Cisco"` — искать строго целое слово (предотвращает ложные совпадения с `CiscoIOS`).
- `grep -i` — игнорировать регистр букв.
- `grep -v '^$'` — инверсия: отбросить все пустые строки.

```bash
# Экранирование спецсимволов: поиск точки как физического знака, а не как регулярки "любой символ"
grep ' w\.' text_file.txt
```

### awk (Построчный парсинг и обработка)

Мощный инструмент, работающий с текстом как с таблицей (столбцы: `$1`, `$2`, вся строка: `$0`).

```bash
# Пропуск первой строки-заголовка с помощью встроенного счетчика строк FNR
df -h / | awk 'FNR > 1 {print $4}'

# Задание кастомного разделителя через регулярное выражение (любое количество двоеточий)
echo "user:::::group" | awk -F ':*' '{print $2}'  # Вывод: group
```

## Объединение и дедупликация потоков

- **`cat`**: Последовательное слияние файлов сверху вниз (вертикальный append).
- **`tac`**: Переворот потока строк задом наперед (последняя строка становится первой).
- **`paste`**: Склеивание файлов по горизонтали в столбцы (по умолчанию через разделитель `\t`).

```bash
# Склеить строки двух файлов через запятую: paste -d, file1 file2
paste -d, titles.txt names.txt
```

- **`diff`**: Построчное сравнение двух конфигурационных файлов.

```bash
# Вычленить строго измененные или добавленные строки из diff без служебных символов
diff config.old config.new | grep '^[<>]' | cut -c3-
```

## Преобразование и трансформация данных (Трансформеры)

### tr (Посимвольная замена)

Работает быстро, так как оперирует на уровне отдельных байт, но **не поддерживает многобайтовые UTF-8 символы** (кириллицу).

```bash
# Быстрая замена двоеточий на переводы строк (парсинг $PATH)
echo $PATH | tr : "\n"

# Удаление всех пробелов и табов из входящего потока данных
echo "text   with   spaces" | tr -d ' \t'
```


### rev (Посимвольный переворот)

Разворачивает зеркально каждый символ в строке. Применяется для быстрого выделения расширений файлов с конца строки в сложных bash-скриптах.

```bash
echo "ReverseMe" | rev  # Вывод: eMesreveR
```

### Сравнение sed и awk для быстрых инлайн-замен

- **`sed`**: Идеален для потоковой подмены текста по регулярным выражениям (`s/шаблон/замена/`).
- **`awk`**: Идеален для перестановки полей и логических условий.

```bash
# Быстрая замена расширения файла силами sed
echo image.jpg | sed 's/\.jpg/.png/'

# Поменять два первых слова (столбца) в строке местами с помощью awk
echo "alpha beta" | awk '{print $2, $1}'  # Вывод: beta alpha
```
