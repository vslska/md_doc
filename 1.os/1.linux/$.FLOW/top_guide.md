# Руководство по использованию утилиты top в Linux

>Утилита **top** представляет собой интерактивный инструмент командной строки для мониторинга системных ресурсов и процессов в режиме реального времени. Настоящее руководство описывает основные принципы работы, интерфейс и ключевые команды управления.

## Запуск и основные параметры командной строки

Синтаксис запуска: `top [опции]`

*   `-d [секунды]`: Установка интервала обновления экрана (по умолчанию — 3.0 секунды).
*   `-u [имя_пользователя]`: Фильтрация отображаемых процессов по конкретному пользователю.
*   `-p [PID]`: Мониторинг процесса или процессов с конкретными идентификаторами.
*   `-b`: Пакетный режим (Batch mode). Используется для вывода данных в файлы или для интеграции со скриптами.
*   `-n [число]`: Ограничение количества циклов обновления в пакетном режиме.

## Структура интерфейса

Интерфейс утилиты разделен на две основные зоны: сводную панель системы и таблицу процессов.

### Сводная панель (Верхняя часть)
*   **Строка 1 (Сводная информация):** Текущее системное время, время непрерывной работы системы (uptime), количество активных пользовательских сессий и средняя загрузка системы (Load Average за 1, 5 и 15 минут).
*   **Строка 2 (Tasks):** Общее количество процессов, разделенных по состояниям: выполняемые (running), ожидающие (sleeping), остановленные (stopped) и процессы-зомби (zombie).
*   **Строка 3 (%Cpu(s)):** Распределение процессорного времени (в процентах):
    *   `us` (user): Процессы пользователя.
    *   `sy` (system): Процессы ядра.
    *   `ni` (nice): Процессы с измененным приоритетом.
    *   `id` (idle): Время простоя.
    *   `wa` (iowait): Ожидание завершения операций ввода-вывода.
    *   `hi` / `si`: Обработка аппаратных и программных прерываний.
*   **Строки 4 и 5 (MiB Mem / MiB Swap):** Состояние оперативной памяти и пространства подкачки: общий объем, свободный объем, используемый объем и буферы/кэш.

### Таблица процессов (Нижняя часть)
*   **PID**: Идентификатор процесса.
*   **USER**: Имя пользователя, запустившего процесс.
*   **PR / NI**: Приоритет процесса (Priority) и значение Nice (влияет на приоритет).
*   **VIRT**: Виртуальный объем памяти, используемый процессом.
*   **RES**: Резидентная (физическая) память, занятая процессом.
*   **SHR**: Объем разделяемой памяти.
*   **S**: Статус процесса (`R` — выполнение, `S` — сон, `D` — непрерывный сон, `Z` — зомби, `T` — остановлен).
*   **%CPU / %MEM**: Процент использования ресурсов процессора и оперативной памяти.
*   **TIME+**: Суммарное время работы процессора, выделенное процессу.
*   **COMMAND**: Имя команды или путь к исполняемому файлу.

## Интерактивные команды управления

Управление отображением данных осуществляется посредством горячих клавиш во время работы утилиты.

### Сортировка данных
*   `M` (регистрозависимая): Сортировка таблицы по уровню использования оперативной памяти (`%MEM`).
*   `P` (регистрозависимая): Сортировка таблицы по уровню загрузки процессора (`%CPU`).
*   `T` (регистрозависимая): Сортировка таблицы по времени работы (`TIME+`).
*   `N` (регистрозависимая): Сортировка по идентификатору процесса (`PID`).
*   `R` (регистрозависимая): Инверсия текущего порядка сортировки (по возрастанию / по убыванию).

### Управление процессами
*   `k`: Завершение процесса. После нажатия требуется ввести `PID` процесса и номер сигнала (по умолчанию посылается `SIGTERM` / 15; для принудительного завершения используется `SIGKILL` / 9).
*   `r`: Изменение приоритета процесса (Renice). Требуется указать `PID` процесса и новое значение Nice (от -20 до 19).

### Настройка отображения интерфейса
*   `1`: Переключение режима отображения ядер процессора (вывод суммарной статистики или детализация по каждому ядру отдельно).
*   `m`: Изменение формата отображения статистики оперативной памяти (текстовый вид / графические шкалы).
*   `t`: Изменение формата отображения статистики процессора.
*   `c`: Переключение режима вывода команды (только имя процесса или полный путь запуска с аргументами).
*   `V`: Древовидное отображение связей процессов (Parent-Child).
*   `h`: Вызов встроенной справки по доступным командам.
*   `q`: Выход из утилиты.
