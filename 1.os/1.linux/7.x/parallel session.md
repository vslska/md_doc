При необходимости установить факт одновременной работы под одной учётной записью с различных хостов применяются перечисленные ниже команды.

## Оперативный просмотр истории входов (команда `last`)

Команда `last` производит поиск по файлу `/var/log/wtmp` и отображает список всех пользователей, входивших в систему и выходивших из неё с момента создания файла . Опция `-i` предписывает вывод IP-адреса вместо имени хоста .

```bash
last -i $(whoami)
```

**Интерпретация:** в третьей колонке выводится IP-адрес, с которого выполнено подключение. Признаком параллельной сессии служит совпадение времени входа при различающихся IP-адресах.

## Аудит через журнал авторизации (`auth.log`)

Журнал `/var/log/auth.log` в Debian фиксирует события аутентификации, включая успешные SSH-подключения с указанием метода (пароль или открытый ключ) и источника .

### Поиск в текущем журнале:

```bash
sudo grep "Accepted" /var/log/auth.log | grep "$(whoami)"
```

### Поиск в архивированных журналах:

Файлы `auth.log.1` и `auth.log.*.gz` содержат более ранние записи; для сжатых архивов применяется `zgrep` .

```bash
sudo zgrep "Accepted" /var/log/auth.log* | grep "$(whoami)"
```

**Пример записи:**
> `Accepted publickey for username from 192.168.1.150 port 51234 ssh2: RSA SHA256:...`

Поле `192.168.1.150` содержит IP-адрес подключившегося хоста.

## Проверка активных сессий

### Список пользователей и источников подключения:

Команда `w` отображает текущие сессии с указанием удалённого хоста для каждой .

```bash
w
```

Для вывода IP-адреса вместо имени хоста применяется опция `-i` (доступна не во всех сборках; зависит от способа компиляции `w`) .

### Дерево процессов с идентификаторами:

```bash
pstree -p $(whoami)
```

### Устаревшая конструкция:

Команда `who -p` в актуальных версиях `who` из состава util-linux не документирована как опция для вывода процессов, порождённых init . Для перечисленных задач данная конструкция не требуется.
