## Установка и первоначальная настройка

### Установка в Arch Linux

Для установки актуальной версии клиента Yandex Cloud c AUR:

```bash
yay -S yandex-cloud-cli-bin
```

### Аутентификация и инициализация профиля

После установки выполняется инициализация интерактивной сессии аутентификации через OAuth-токен:

```Bash
yc init
```

После выполнения команды автоматически откроется браузер, где потребуется авторизоваться в учетной записи Yandex Cloud и скопировать токен. Полученный токен утилита запишет в конфигурационный файл `~/.config/yandex-cloud/config`.

### Ручная настройка конфигурации

Параметры окружения (облако, каталог, токен) можно задать вручную через команды `yc config set`:

```Bash
yc config set token "AQAAAA..."
yc config set cloud-id "b1g..."
yc config set folder-id "b1a..."
```

Проверка текущей конфигурации и состояния доступных ресурсов:

```Bash
yc config list
yc compute instance list
```

## Архитектура и основные группы команд

Интерфейс командной строки `yc` структурирован по сервисам Yandex Cloud:

| Группа команд | Поддерживаемые действия | Назначение |
|---|---|---|
| **`yc compute`** | `instance create`, `disk list`, `image get` | Управление виртуальными машинами, дисками и системными образами. |
| **`yc vpc`** | `network create`, `subnet list` | Управление виртуальными сетями, подсетями и маршрутизацией. |
| **`yc storage`** | `bucket create`, `object cp` | Работа с S3-совместимым объектным хранилищем Object Storage. |
| **`yc iam`** | `token create`, `service-account get` | Управление доступом, сервисными учетными записями и ключами. |
| **`yc logging`** | `group list`, `export create` | Централизованный сбор логов и экспорт в системы мониторинга. |
| **`yc monitoring`** | `alert create`, `dashboard list` | Настройка метрик, дашбордов и алертинга. |

## Практические сценарии (One-Liners для автоматизации)

### Создание виртуальной машины

Быстрое развертывание новой ВМ на базе Ubuntu 22.04 LTS с привязкой публичного IP-адреса и загрузкой SSH-ключа:

```bash
yc compute instance create \
  --name dragon-vm \
  --zone ru-central1-a \
  --network-interface subnet-name=default,nat-ip-version=ipv4 \
  --ssh-key ~/.ssh/id_ed25519.pub \
  --create-boot-disk image-folder-id=standard-images,image-family=ubuntu-2204-lts,size=20
```

### Получение внешнего IP-адреса для скриптов

Извлечение публичного IPv4-адреса созданной виртуальной машины в формате JSON с обработкой через `jq`:

```bash
yc compute instance get dragon-vm --format json | jq -r '.network_interfaces[0].primary_v4_address.one_to_one_nat.address'
```

### Работа с объектным хранилищем S3

Загрузка локального файла (например, отчета) в бакет объектного хранилища:

```bash
yc storage cp report.pdf storage://my-bucket/
```

### Создание сервисного аккаунта и ключа для Terraform

Регистрация нового сервисного аккаунта и генерация ключа доступа в файл `key.json`:

```bash
yc iam service-account create --name terraform-sa
yc iam access-key create --service-account-name terraform-sa --output key.json
```

## Управление токенами, профилями и безопасность

### Работа с IAM-токенами и профилями

| Задача | Команда |
|---|---|
| **Получить временный IAM-токен** (для REST API) | `yc iam create-token` |
| **Список профилей конфигураций** | `yc config profile list` |
| **Переключиться на другой профиль** | `yc config profile activate prod` |

### Экспорт переменных окружения для Terraform и автоматизации

Для передачи текущего контекста Yandex Cloud в сторонние утилиты (например, Terraform или скрипты деплоя) конфигурация экспортируется в переменные среды:

```bash
export YC_TOKEN=$(yc iam create-token)
export YC_CLOUD_ID=$(yc config get cloud-id)
export YC_FOLDER_ID=$(yc config get folder-id)
```

### Фильтрация и вывод данных в машиночитаемом формате

Использование флага `--format json` или `--format yaml` совместно с `jq` позволяет строить сложные выборки данных:

```bash
yc vpc subnet list --folder-id b1a... --format json | jq '.[].id'
```

## Интеграция `yc` в инженерные workflow

- **Для Terraform:** Генерация статического ключа (`yc iam access-key create` → `key.json`) с последующим подключением через блок провайдера `yandex { service_account_key_file = "key.json" }`.
- **Для Ansible:** Организация динамического инвентаря серверов на базе вывода команды `yc compute instance list --format json`.
- **Для систем резервного копирования:** Передача архивов (`borg` / `tar`) в облачный бакет с помощью команды `yc storage cp`.
- **Для мониторинга:** Создание автоматизированных алертов и метрик через `yc monitoring alert create` с интеграцией отправки уведомлений в Telegram или вебхуки.
